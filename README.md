# Polymarket «insider» backtest

Можно ли заработать, повторяя за подозрительными крупными ставками на Polymarket? Проверка на 27 967 ставках от $2 000 (июнь 2025 – октябрь 2026).

**Ответ: нет.** Самые «инсайдерские» ставки дали −42% на доллар. Вся прибыль дешёвых ставок пришлась на 5 событий, без них −14%. Разбор — в Telegram-канале [Архитектор | За кулисами бота](https://t.me/architectkulees).

## Как устроено

| Шаг | Скрипт | Что делает |
|---|---|---|
| 1 | `collect_markets.py` | Закрытые рынки с оборотом от $100 тыс. (Gamma API) |
| 2 | `collect_trades.py` | Тейкерские сделки от $2 000 в каждом рынке (Data API) |
| 3 | `collect_wallets.py` | История кошелька до момента сделки: возраст, число сделок, доля в рынке |
| 4 | `backtest.py` | Балл «подозрительности» по правилу, записанному заранее, доход на $1, бутстрэп по событиям |
| 5 | `follow.py` | Вход подписчика через 1/5/15/60 минут с проскальзыванием 1 цент (CLOB prices-history) |
| — | `charts.py` | Графики для постов |

Правило баллов в `backtest.py → score()` зафиксировано до просмотра результатов. Признаки кошелька считаются только по данным до сделки, без заглядывания в будущее. Учитываются только покупки: продажа исхода — это выход из позиции, а не ставка на противоположный.

## Запуск

Нужен Python 3.10+ и доступ к API Polymarket (в некоторых странах нужен VPN).

```bash
python3 collect_markets.py
python3 collect_trades.py
python3 collect_wallets.py   # самый долгий шаг, ~25 тыс. кошельков
python3 backtest.py report.md
python3 follow.py 8
pip install matplotlib && python3 charts.py
```

Данные сохраняются в `data/` (в репозиторий не входят, около 100 МБ).

## Ограничения

- Спортивные рынки взяты случайной выборкой в 3 000.
- Не проверялось, пополнялись ли кошельки из одного источника.
- Только сделки от $2 000.

Это исследование, а не инвестиционная рекомендация.
